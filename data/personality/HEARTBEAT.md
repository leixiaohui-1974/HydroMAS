# HEARTBEAT.md — 主动巡检配置

## 检查项目

### 1. 系统健康 (每15分钟)
- 检查 HydroMAS API 可用性: GET /api/system/status
- 检查五层架构各层状态: L0_core → L4_agents
- 如果不是 "online"，立即推送飞书告警

### 2. ODD 安全域扫描 (每小时)
- 运行全维度 ODD 检查
- 正常(normal): 不做任何操作
- 预警(extended): 推送黄色告警到飞书
- 越界(mrc): 推送红色告警 + 触发 MRC 应急降级

### 3. 水平衡残差检测 (每小时)
- 检查各节点水平衡残差
- 残差超过阈值(>5%): 推送异常告知
- 连续2次异常: 触发泄漏检测流程

### 4. 记忆整理 (每4小时, 仅在 08:00-22:00)
- 读取当日 daily notes
- 识别重复出现的问题模式
- 将重要发现沉淀到 MEMORY.md

### 5. 资源监控 (每小时)
- 磁盘使用率 > 85%: 推送清理提醒
- 内存使用率 > 90%: 推送告警
- 交互日志文件超过 50MB: 触发归档

### 6. 自进化触发 (每天凌晨 03:00)
- 分析过去24小时的交互日志
- 生成改进建议报告
- 推送到开发组飞书群

## 告警通道
- 飞书 Webhook: ${FEISHU_ALERT_WEBHOOK_URL}
- 严重级别: info → 仅记录 | warning → 推送管理组 | critical → 推送全部
